📌 Tentang Project Ini
Halo! Project ini saya bangun untuk mempermudah proses instalasi, manajemen web server, serta melakukan hardening (pengamanan) dasar dan audit sistem pada VPS Linux.

Script ini di-coding dengan bantuan AI (Claude) untuk memastikan standar sintaks yang baik, namun logikanya dirancang khusus untuk menghadapi skenario ancaman real-world. Sangat cocok digunakan oleh sysadmin pemula maupun developer yang ingin men-deploy web tanpa pusing memikirkan konfigurasi dari nol.

⚠️ Filosofi & Peringatan (WAJIB BACA)
Tidak Ada Sistem yang 100% Aman: Tidak ada satu pun kode di dunia ini yang sempurna. Keamanan siber adalah proses yang berjalan terus-menerus (continuous process), bukan setup sekali jadi. Selalu pastikan VPS dan sistem kamu up-to-date.

Asisten, Bukan Pengganti: Script ini bertugas untuk membantu dan mengotomatisasi pekerjaan yang repetitif. Script ini TIDAK menggantikan pemahaman fundamental kamu. Jangan biarkan server kamu dijajah oleh pihak tak bertanggung jawab hanya karena kamu mengeksekusi script secara buta tanpa tahu fungsinya.

AI-Assisted Learning: Jika ada fitur atau baris kode .sh di dalam repositori ini yang kurang kamu pahami, saya sangat menyarankan untuk meng-copy kode tersebut, paste ke AI (Claude/Gemini/ChatGPT), dan minta penjelasan "step-by-step".

🚀 Fitur Utama
⚙️ Automated Web Server Setup: Pilihan instalasi cepat untuk Nginx atau Apache.

🛡️️ Basic Security Hardening: Konfigurasi otomatis untuk firewall dan pencegahan eksploitasi dasar.

📊 Audit Trail Logging: Merekam jejak setup (history) yang bisa diekspor untuk dianalisis kerentanannya oleh AI.

🗄️ Instant Database & Panel: Integrasi langsung dengan MariaDB dan Adminer untuk kemudahan akses.
